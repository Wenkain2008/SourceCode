Overview

Project Jarvis is an experimental local AI agent built around Ollama, with the goal of providing an agent capable of interacting with the local system through controlled execution and read/write access.

The project is currently under active development. Functionality, documentation, configuration instructions, and safety mechanisms are still being implemented and will be expanded over time.

At this stage, the project should be considered experimental and potentially unsafe.

Project Goals

The primary goals of Project Jarvis are to develop a local AI agent with:

Local LLM support through Ollama

Controlled command and code execution

Read access to the local filesystem

Write access to the local filesystem

Configurable safety limits and execution boundaries

A framework for progressively improving agent autonomy while maintaining appropriate safeguards


Safety Warning

Project Jarvis can potentially damage your system.

The project's safety limits and execution boundaries are still under development. Until these safeguards are fully implemented and tested, the agent may have access to operations that can modify, delete, or otherwise affect files and system resources.

Do not run this project or any code generated by it unless you understand exactly what the code does and what permissions it has.

In particular:

Do not run the agent on a system containing important or irreplaceable data without appropriate backups.

Do not grant the agent permissions you do not fully understand.

Review commands and code before execution.

Assume that current safety mechanisms may be incomplete or ineffective.

Use an isolated environment or virtual machine for testing whenever possible.
